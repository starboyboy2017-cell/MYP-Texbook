Statement of inquiry A pattern becomes mathematics when it is described by a general rule, and a rule be- comes useful when it can be rearranged to answer a question about a value that is not yet known.
Key and related concepts
Key concept · Relationships. An expression records how one quantity depends on another, which is why substitut-
ing a value produces a predictable result.
Related · Pattern. A linear pattern changes by a constant difference, and that constant is the coefficient in the rule.
Related · Generalisation. A rule stated with a letter holds for every case, not only the cases examined.
Global context · Personal and cultural expression
Exploration: how weaving, tiling and ornament use repeating structures, and how the same structure can be de-
scribed in words, in a table, in a graph and in a rule.
Inquiry questions
– Factual: How do you find the next term of a sequence, and how do you substitute into an expression?
– Conceptual: Why does solving an equation preserve the equality when you do the same thing to both
sides?
– Debatable: Is a rule more useful in words, in a table, in a graph or in symbols?

The loom.
A narrow-strip weaver repeats one motif along a long band. Each repeat adds the same length of cloth. If she
knows the length of one motif and the length of the starting border, she can predict the length of a band with
any number of motifs without measuring it — provided she has found the rule.
A repeating motif is a linear pattern: the length grows by a constant amount per repeat. Algebra is the shortest way to write that sentence.

nth term
The nth term of a linear sequence is an expression in n that gives the
value at position n. If the first term is a and the common difference is d,
then the nth term is a + (n − 1)d.
P R O B L E M Find the nth term of the sequence 5, 8, 11, 14, …
1 The difference between consecutive terms is 3, so the rule con- tains 3n.
2 Compare 3n with the terms: for n = 1, 3n = 3, but the term is 5.
3 The rule must add 2: 3n + 2.
4 Check with n = 3: 3 × 3 + 2 = 11, which matches the third term.
n = 4 gives 14 ✓ and n = 1 gives 5 ✓

6.2 Expressions and substitution
Expression, term, coefficient
An expression combines numbers, letters and operations without an
equals sign: 3x + 5. A term is one part of it separated by + or −. A coeffi-
cient is the number multiplying a letter: in 3x, the coefficient is 3.
Substituting a value into an expression is a test of whether you can
read its structure. In 3x + 5, the multiplication happens before the ad-
dition, so x = 2 gives 11, not 16.

6.3 Simplifying and expanding

<!-- printed page 102 -->
Like terms contain the same letter with the same power, so they can
be combined: 3x + 5x = 8x because three lots of x plus five lots of x is
eight lots of x. Unlike terms such as 3x and 3x2 cannot be combined,
because they count different things.
Expanding a bracket
A bracket is a multiplication: 3(x + 4) means three copies of (x + 4). Mul-
tiplying each term inside by the number outside gives 3x + 12. This is the
distributive law, and it is the reverse of factorising.
P R O B L E M Simplify 7a + 3b − 2a + 5b.
1 Collect the a terms: 7a − 2a = 5a.
2 Collect the b terms: 3b + 5b = 8b.
3 The simplified expression is 5a + 8b; the two terms are unlike, so they stay separate.
Substitute a = 1, b = 1: original gives 7 + 3 − 2 + 5 = 13; simplified gives 5 + 8 = 13 ✓
P R O B L E M Expand and simplify 4(x + 3) + 2(x − 1).
1 Expand each bracket: 4x + 12 and 2x − 2.
2 Add the results: 4x + 12 + 2x − 2.
3 Collect like terms: 6x + 10.
x = 2: original 4(5) + 2(1) = 22; simplified 12 + 10 = 22 ✓
3x + 4 = 7x
Adding unlike terms is not allowed. 3x + 4 stays as it is; only if the
second number also multiplies x can the two be combined. Substitute a
value to see the difference: with x = 10, 3x + 4 = 34, not 70.

6.4 Equations and formulas
Equation and solution
An equation states that two expressions are equal: 3x + 2 = 11. A solution
is the value of the letter that makes the statement true. Solving means
finding that value, not guessing it.

F I G U R E 3 An equation is a balance. Whatever is done to one side must be done to the other, or the equality is destroyed.
The method
– Undo addition or subtraction first, using the inverse operation on
both sides.
– Undo multiplication or division second.
– Check by substituting the solution back into the original equation.
– Keep the equals signs aligned so that each line states a true equal-
ity.

1 Subtract 7 from both sides: 4x = 24.
2 Divide both sides by 4: x = 6.
3 Check: 4 × 6 + 7 = 24 + 7 = 31.
Substitution returns the original right-hand side ✓
P R O B L E M Solve 3(x − 2) = 18.
1 Divide both sides by 3: x − 2 = 6.
2 Add 2 to both sides: x = 8.
3 Alternatively expand first: 3x − 6 = 18, so 3x = 24 and x = 8.
3(8 − 2) = 18 ✓
P R O B L E M The perimeter of a rectangle is P = 2(l + w). Find l when P = 26 and w = 4.
1 Substitute: 26 = 2(l + 4).
2 Divide by 2: 13 = l + 4.
3 Subtract 4: l = 9.
2(9 + 4) = 26 ✓
Doing an operation to one side only
From 4x + 7 = 31, subtracting 7 from the left alone gives 4x = 31, which is
false. The balance metaphor is precise: an equation is a statement of
equality, and equality survives only if both sides change together.

Your investigation
1. Count the matchsticks for 1, 2, 3 and 4 squares.
2. Explain in words why the count does not grow by 4 each time.
3. Find the constant difference and write the rule.
4. Predict the number of matchsticks for 20 squares and check by calculation.
5. How many squares can be made with 100 matchsticks? Write the equation you solved.
6. Now build a different chain: an L-shape, or a row of triangles. Find its rule and compare the constant dif-
ferences.
Why the rule has that shape
The first square needs 3 matchsticks plus the closing side: 4. Each extra square adds 3. So matchsticks = 3n + 1. The
constant 3 is the number of new matchsticks per square; the +1 is the side that closes the first square.

What this chapter established
– A linear pattern has a constant difference, which appears as the coefficient.
– The nth term lets you answer questions about any position without listing.
– Substituting into an expression tests whether you can read its structure.
– Like terms can be combined; unlike terms cannot.
– Solving an equation means keeping a balance true at every step.
Vocabulary
Term Meaning
sequence An ordered list of numbers.
nth term An expression giving the value at position n.
expression A combination of numbers, letters and operations.
term One part of an expression separated by + or −.
coefficient The number multiplying a letter.
expand Multiply out a bracket.
equation A statement that two expressions are equal.
solution The value that makes an equation true.
Misconceptions to watch
Three that persist
3x + 4 = 7x. 4 is not a number of x.
5(x + 2) = 5x + 2. The 5 multiplies both terms.
Moving a term without changing its sign. Subtract from both sides rather than “moving”.
