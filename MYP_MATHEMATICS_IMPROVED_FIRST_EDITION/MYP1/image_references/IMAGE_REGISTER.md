# Image register

Every image in this edition is either vector artwork drawn in code or an original
illustration generated for this edition. No stock photograph, publisher image, web
image or scan is reproduced anywhere in the book.

The chapter plates share one palette (deep green, cream, sand, terracotta, sage) and
one flat-ink line-and-wash style so that they read as a single series. Each plate is
used at a fraction of its source resolution, so the printed copy carries no visible
pixel structure at 300 dpi equivalent.

The banner derivatives are crops, produced once and stored beside the originals;
the originals are never modified.

## 2. Vector artwork (drawn in code, not rasterised)

All figures in the book are produced by `build/diagrams.py` and `build/bookkit/plates.py`
and drawn straight into the PDF, so they stay sharp at any output size. The set covers:

* number lines, place-value tables, expanded-form strips and rounding diagrams (Ch 1)
* power, square-root, index and order-of-operations diagrams (Ch 2)
* factor trees, arrays and prime-grid diagrams (Ch 3)
* fraction strips, equivalence bars and decimal grids (Ch 4)
* percentage bars, discount and price panels (Ch 5)
* tile and matchstick sequence diagrams (Ch 6)
* angle, parallel-line, polygon and construction figures (Ch 7)
* set and Venn diagrams, two-way classification tables (Ch 8)
* perimeter, area, circle, net, prism and composite-shape figures (Ch 9)
* frequency tables, bar charts, dot plots, pie charts and honest/misleading axes (Ch 10)

No vector artwork is traced from, or adapted from, any published source.

## 4. Assets deliberately not used

* No image from the source PDF is reused, at any resolution.
* No image from Wikimedia Commons, Unsplash or a publisher site is included.
* No map, photograph of a person, or recognisable brand appears in the book.
