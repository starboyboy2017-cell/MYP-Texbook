Functions, expressions
and algebraic reasoning
Algebra begins when a letter stands for a number we
have not chosen yet. It becomes powerful when the
letter describes a relationship: one quantity
determines another, and the rule can be written,
tabulated, graphed and transformed.

I N Q U I R Y
How can a single expression capture a whole family of cases — and how
do we know that two different-looking expressions describe exactly the
same relationship?
AT L · T H I N K I N G I N AC T I O N
When you meet a new expression, ask three questions: What are the inputs? What operations are
performed, and in what order? What changes if one operation changes? Treat an expression as a
description of a process, not a string of symbols to memorise. This habit makes expanding, factorising
and rearranging easier to reconstruct when memory fails.

KEY AND RELATED CONCEPTS
Relationships. A function assigns each input
exactly one output. The relationship can be
represented by a rule, a table, a graph, a machine
diagram or a set of ordered pairs.
Generalisation. An expression such as 
stands for infinitely many numerical cases at
once. Generalising is the move from “this pattern
works here” to “this rule works for every
position”.
Equivalence. Expressions that look different can
have the same value for every input. Expanding
and factorising are tools for revealing that
equivalence.
GLOBAL CONTEXT AND EXPLORATION
Identities and relationships. Exploration:
how a function describes a dependable
relationship between two quantities, and
how the same relationship can appear in a
table, a graph, a formula or a machine.
Functions are the language of dependence:
the cost depends on the quantity, the height
depends on the time, the area depends on
the side length. Learning to name the input,
the output and the rule is the first step in
modelling any relationship.
