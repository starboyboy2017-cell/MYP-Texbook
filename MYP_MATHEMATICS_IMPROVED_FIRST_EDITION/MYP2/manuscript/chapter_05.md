## 5.1 The language of algebra

**Criterion A · I · C · I** · Related concepts: Relationships, Notation

> Algebra is compressed reasoning. A letter stands for a number, and everything written around it is a statement about what would happen to that number.

### 05 · EXPLAIN

A *variable* is a letter standing for a number that may change. A *term* is a single number, letter or product of them; an *expression* combines terms with operations and has no equals sign; an *equation* states that two expressions are equal. *Like terms* have exactly the same letters with the same indices.

Notation is conventional and worth learning exactly: 3*n* means 3 × *n*; *n*/5 means *n* ÷ 5; *n*² means *n* × *n*. Writing 3*n* and never 3 × *n* is not laziness — it keeps the coefficient visually separate from the variable, which makes collecting terms possible.

[Figure: algebra_tiles — Algebra tiles for 3*x* + 4 − 2*x*. Like tiles cancel in pairs, which is what collecting terms does symbolically.]

### Substitution

Substituting means replacing each letter with a number, in brackets if the number is negative, and then evaluating by the order of operations.

**Worked example 5.1.1 — Substitute a negative value**

Evaluate 4*x* − 3 when *x* = −2, and when *x* = 1.5.

1. Write the substitution with brackets: 4(−2) − 3.
2. Multiply first: −8 − 3 = −11.
3. For *x* = 1.5: 4(1.5) − 3 = 6 − 3 = 3.
4. Check the second by another route: 4 × 1.5 = 6, and 6 − 3 = 3.

*Answer:* −11 and 3

*Check:* The brackets are not optional: 4 × −2 − 3 invites a sign error, while 4(−2) − 3 does not.

**Worked example 5.1.2 — Write an expression**

A taxi charges £4 plus £2 per kilometre. Write an expression for the cost of *k* kilometres, and find the cost of 7 km.

1. The distance part costs 2*k* pounds.
2. The fixed charge is added: 2*k* + 4.
3. For *k* = 7: 2(7) + 4 = 18.
4. The cost is £18.

*Answer:* 2*k* + 4; £18 for 7 km

*Check:* Check a simple case: 1 km should cost £2 + £4 = £6, and 2(1) + 4 = 6.

**Worked example 5.1.3 — Interpret an expression**

An expression for the total cost of a school trip is 12*n* + 45. Explain what each part means and find the cost when *n* = 30.

1. 12*n* is a cost per student, so 12 is the cost in pounds for each of *n* students.
2. 45 is a fixed cost that does not depend on the number of students: a minibus hire, for example.
3. For *n* = 30: 12(30) + 45 = 360 + 45 = 405.
4. The total cost is £405.

*Answer:* £12 per student plus a fixed £45; £405 for 30 students

*Check:* If *n* = 0 the cost is £45, confirming the fixed part.

“3*n* means 3 followed by *n*, that is, 3*n* = 30 when *n* = 0.” Juxtaposition means multiplication: 3*n* = 3 × *n*, which is 0 when *n* = 0. The coefficient is a multiplier, never a digit.

## 5.2 Equivalent expressions

**Criterion A · II · C · II** · Related concepts: Equivalence, Simplification

> Two expressions are equivalent when they give the same value for every value of the variable. Simplifying is the art of finding a shorter form that keeps every value.

Expressions are *equivalent* when substituting any number for the variable gives the same result in both. Collecting like terms and expanding brackets both produce equivalent expressions, because they follow from the distributive and commutative laws.

### Two operations that preserve value

- **Collecting like terms.** 5*a* + 3*b* − 2*a* simplifies to 3*a* + 3*b*: the *a*-terms are combined and the *b*-term is untouched.
- **Expanding brackets.** 3(2*x* − 4) becomes 6*x* − 12: every term inside is multiplied by the factor outside.

### Testing equivalence

To show two expressions are equivalent, simplify both and compare, or substitute two different values and check both give the same result. To show they are not, one counterexample is enough — and it is also complete.

**Worked example 5.2.1 — Simplify by collecting**

Simplify 7*x* + 4 − 3*x* + 9 − *x*.

1. Collect the *x*-terms: 7*x* − 3*x* − *x* = 3*x*.
2. Collect the numbers: 4 + 9 = 13.
3. The simplified expression is 3*x* + 13.
4. Check with *x* = 2: original 14 + 4 − 6 + 9 − 2 = 19; simplified 3(2) + 13 = 19.

*Answer:* 3*x* + 13

*Check:* A single substitution catches most collecting errors, which is why it is worth doing.

**Worked example 5.2.2 — Expand and simplify**

Simplify 4(2*x* + 3) − 2(*x* − 5).

1. Expand the first bracket: 4(2*x* + 3) = 8*x* + 12.
2. Expand the second, keeping the minus sign with every term: −2(*x* − 5) = −2*x* + 10.
3. Collect: 8*x* − 2*x* + 12 + 10 = 6*x* + 22.
4. Check with *x* = 1: original 4(5) − 2(−4) = 20 + 8 = 28; simplified 6 + 22 = 28.

*Answer:* 6*x* + 22

*Check:* The common error is writing −2(*x* − 5) = −2*x* − 10. Both terms inside change sign.

**Worked example 5.2.3 — Are they equivalent?**

Are 3(*x* + 2) and 3*x* + 2 equivalent? Are 2(*x* + 3) and 2*x* + 6?

1. Expand 3(*x* + 2) = 3*x* + 6, which differs from 3*x* + 2.
2. Test *x* = 1: 3(3) = 9 but 3 + 2 = 5. One counterexample proves they are not equivalent.
3. Expand 2(*x* + 3) = 2*x* + 6, which is identical to the second expression.
4. Both are correct statements, but only the second pair is equivalent.

*Answer:* 3(*x* + 2) ≡ 3*x* + 6, so the first pair is not equivalent; the second pair is.

*Check:* Expanding is the test; a counterexample settles a negative answer.

“3(*x* + 2) = 3*x* + 2, because the 3 only multiplies the first term.” The factor outside a bracket multiplies every term inside: 3(*x* + 2) = 3*x* + 6. Substituting *x* = 1 exposes the error immediately.

## 5.3 Solving linear equations

**Criterion A · III · C · III** · Related concepts: Equivalence, Balance

> An equation is a balance. Whatever you do to one side, you must do to the other, until the unknown stands alone.

[Figure: balance — A balance with three *x*-tiles on one side and six unit tiles on the other. Removing the same quantity from both sides keeps it level.]

### The balance method

1. Simplify each side if necessary, expanding any brackets.
2. Undo addition or subtraction first, using the inverse operation on both sides.
3. Undo multiplication or division last.
4. Check by substituting the solution into the original equation.

The order matters. Undoing the operations in reverse order of their application is exactly what keeps the working readable: if the unknown was multiplied and then added to, we subtract first, then divide.

**Worked example 5.3.1 — Two steps**

Solve 4*x* − 7 = 21.

1. Add 7 to both sides: 4*x* = 28.
2. Divide both sides by 4: *x* = 7.
3. Check: 4(7) − 7 = 28 − 7 = 21, as required.
4. Report the solution as *x* = 7.

*Answer:* *x* = 7

*Check:* Substitution is not optional: it is the only evidence that the solution is right.

**Worked example 5.3.2 — Unknown on both sides**

Solve 3(*x* + 2) = 5*x* − 4.

1. Expand the left side: 3*x* + 6 = 5*x* − 4.
2. Collect the unknown on one side: subtract 3*x* from both sides, giving 6 = 2*x* − 4.
3. Add 4 to both sides: 10 = 2*x*, so *x* = 5.
4. Check in the original: 3(5 + 2) = 21 and 5(5) − 4 = 21. Both agree.

*Answer:* *x* = 5

*Check:* Collecting the unknown on the side that keeps it positive avoids sign slips.

**Worked example 5.3.3 — A fractional solution**

Solve *x*/3 + 4 = 10.

1. Subtract 4 from both sides: *x*/3 = 6.
2. Multiply both sides by 3: *x* = 18.
3. Check: 18/3 + 4 = 6 + 4 = 10, as required.
4. The solution is a whole number here, but it need not be in general.

*Answer:* *x* = 18

*Check:* Multiplying by the denominator is the inverse of dividing by it.

“4*x* − 7 = 21, so 4*x* = 21 − 7 = 14, so *x* = 3.5.” The 7 was subtracted although it was already being subtracted. Undo −7 by adding 7: 4*x* = 28, so *x* = 7. Check by substitution to settle any doubt.

## 5.6 Summary, revision and reflection

### What this chapter established

- A variable is a number not yet chosen; an expression describes what would happen to it; an equation states an equality to be solved.
- Like terms have identical letters and indices, and only like terms can be collected.
- A factor outside a bracket multiplies every term inside it.
- Equivalent expressions agree for every substitution; one counterexample proves two expressions are not equivalent.
- Solving is undoing: apply inverse operations to both sides, in reverse order of application.
- Every solution should be checked by substitution.

**Vocabulary to use precisely**

**variable** · **term** · **coefficient** · **expression** · **equation** · **like terms** · **simplify** · **expand** · **equivalent** · **substitute** · **solve** · **inverse operation**

### Misconceptions to close

| The mistake | What is really happening |
|---|---|
| “3(*x* + 2) = 3*x* + 2.” | The 3 multiplies both terms: 3*x* + 6. Substituting *x* = 1 shows it. |
| “−2(*x* − 5) = −2*x* − 10.” | Both terms change sign: −2*x* + 10. |
| “4*x* − 7 = 21 gives 4*x* = 14.” | The 7 is subtracted, so it must be added back: 4*x* = 28. |
| “2*x* and 2*x*² are like terms.” | The indices differ, so they cannot be collected: 2*x* + 2*x*² stays as it is. |
