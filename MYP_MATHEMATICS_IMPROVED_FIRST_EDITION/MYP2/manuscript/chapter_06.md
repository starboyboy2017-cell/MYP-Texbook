# Chapter 6 · Numerical patterns and generalisation

*Part II · Algebra and pattern* · key concept **Change** · related concepts: Patterns, Models

Global context: Personal and cultural expression

A sequence is a list with a rule. The interesting question
is never “what comes next?” but “what is the rule,
and how do you know it holds for every term?”

### 01 · MYP UNIT PLANNER

*From a list of numbers to a rule that generates all of them.*

**Statement of inquiry.** A pattern becomes mathematics when its rule is written in terms of the term's position, because a rule can predict terms that have never been counted.

**Key and related concepts**

**Key concept · Change.** A sequence records how a quantity changes from step to step, and a linear sequence changes by a constant amount.
**Related · Patterns.** The *n*th term is the pattern expressed as a formula in *n*.
**Related · Models.** A function machine, a table and a graph are three models of the same rule.

**Global context · Personal and cultural expression**

Exploration: ornament, tilework and building patterns that repeat and grow. A pattern that can be described is one that can be continued, taught and criticised.

### Inquiry questions

- **Factual:** How do you find the next term of a sequence?
- **Conceptual:** Why does the *n*th term make the term-to-term rule unnecessary?
- **Debatable:** Is a pattern established by three terms, or does it need a reason?

### 05 · EXPLAIN

A *sequence* is an ordered list of numbers, each called a *term*. A *term-to-term rule* describes how to get from one term to the next. A sequence whose terms increase or decrease by a constant amount is *linear*, and that constant amount is the *common difference*.

[Figure: matchstick — A growing matchstick pattern. Four sticks make the first square and each extra square needs three more, giving 3*n* + 1 sticks for *n* squares.]

The matchstick pattern is worth studying because the rule can be read from the picture. The first square takes 4 sticks; each extra square shares one side and adds 3 sticks. So *n* squares take 4 + 3(*n* − 1) sticks, which simplifies to 3*n* + 1. A rule found from a picture can be checked against a rule found from a table, and agreement is evidence.

**Worked example 6.1.1 — Find the term-to-term rule**

Write the term-to-term rule for (a) 7, 12, 17, 22, … and (b) 64, 32, 16, 8, … and give the next two terms.

1. (a) The differences are 5 each time, so the rule is “add 5”.
2. Next terms: 27, 32.
3. (b) Each term is half the one before, so the rule is “double or halve”: multiply by 1/2.
4. Next terms: 4, 2.

*Answer:* (a) add 5; 27, 32   (b) multiply by 1/2; 4, 2

*Check:* Check (b) backwards: doubling 4 gives 8, which is in the list.

**Worked example 6.1.2 — A picture to a rule**

A pattern of equilateral triangles is made from sticks: 3 sticks for 1 triangle, 5 for 2, 7 for 3. Find the rule and the number of sticks for 20 triangles.

1. The differences are 2 each time, so the rule is “add 2”.
2. Write the rule in terms of *n*: 2*n* + 1, since *n* = 1 gives 3.
3. For *n* = 20: 2(20) + 1 = 41.
4. Check *n* = 3: 2(3) + 1 = 7, as counted.

*Answer:* 2*n* + 1; 41 sticks

*Check:* The first term fixes the constant: 2(1) + *c* = 3 gives *c* = 1.

**Worked example 6.1.3 — Two rules, one sequence**

For 5, 9, 13, 17, … state the term-to-term rule and a rule for the *n*th term. Which is more useful for finding the 50th term?

1. The common difference is 4, so the term-to-term rule is “add 4”.
2. The *n*th term is 4*n* + 1, since 4(1) + 1 = 5.
3. The 50th term is 4(50) + 1 = 201, found in one step.
4. The term-to-term rule would need 49 additions; the *n*th term needs one calculation.

*Answer:* Add 4; *n*th term 4*n* + 1; 201

*Check:* Check the 50th by the equivalent formula 5 + 4(50 − 1) = 201.

“The sequence is 3, 6, 9, … so the next term must be 12; the rule is ‘add 3’ and that is the only possibility.” Any three terms can be continued in many ways — 3, 6, 9 could be followed by 12 or by 18 (doubling) or by 9 (repeating). A rule becomes a generalisation only when there is a reason for it, usually the structure of a diagram or the context.

## 6.2 The nth term of a linear sequence

**Criterion A · II · B · II** · Related concepts: Patterns, Generalisation

> The *n*th term is a formula that gives any term directly from its position. It turns a list into a rule.

For a linear sequence with first term *a* and common difference *d*, the *n*th term is *a* + (*n* − 1)*d*, which simplifies to *d n* + (*a* − *d*). The coefficient of *n* is always the common difference.

### A reliable method

1. Find the common difference *d*; it becomes the coefficient of *n*.
2. Write *d n* and compare it with the sequence to see what must be added or subtracted.
3. Fix the constant by testing the first term.
4. Check the formula on the second and third terms before trusting it.

**Worked example 6.2.1 — Find the nth term**

Find the *n*th term of 6, 10, 14, 18, …

1. The common difference is 4, so the rule begins 4*n*.
2. For *n* = 1, 4(1) = 4, but the first term is 6, so add 2.
3. The *n*th term is 4*n* + 2.
4. Check: *n* = 2 gives 10 and *n* = 3 gives 14, as listed.

*Answer:* 4*n* + 2

*Check:* Take the difference first, fix the constant second, and always check two terms.

**Worked example 6.2.2 — A decreasing sequence**

Find the *n*th term of 30, 26, 22, 18, …

1. The common difference is −4, so the rule begins −4*n*.
2. For *n* = 1, −4(1) = −4, but the first term is 30, so add 34.
3. The *n*th term is 34 − 4*n*, or −4*n* + 34.
4. Check: *n* = 2 gives 26 and *n* = 4 gives 18.

*Answer:* 34 − 4*n*

*Check:* A decreasing sequence has a negative coefficient of *n*; that is expected, not an error.

**Worked example 6.2.3 — Which term is it?**

The *n*th term of a sequence is 5*n* − 2. Is 88 a term of the sequence?

1. Set 5*n* − 2 = 88 and solve.
2. Add 2: 5*n* = 90, so *n* = 18.
3. Since 18 is a whole number, 88 is the 18th term.
4. Check: 5(18) − 2 = 90 − 2 = 88, as required.

*Answer:* Yes — 88 is the 18th term

*Check:* If the solution for *n* were not a whole number, the value would not be in the sequence.

[Figure: sequence_graph — The terms of 4, 7, 10, 13, … plotted against their position. The points lie on a straight line whose gradient is the common difference.]

**Worked example 6.2.4 — From a graph to a rule**

The terms of a sequence plotted against *n* lie on a straight line through (1, 7) and (3, 15). Find the *n*th term.

1. The gradient is (15 − 7) ÷ (3 − 1) = 8 ÷ 2 = 4, so the rule begins 4*n*.
2. At *n* = 1 the value is 7, so 4(1) + *c* = 7, giving *c* = 3.
3. The *n*th term is 4*n* + 3.
4. Check: *n* = 3 gives 15, which is the second point.

*Answer:* 4*n* + 3

*Check:* The gradient of the term-number graph is the common difference.

“The *n*th term of 5, 8, 11, … is 3*n*, because the difference is 3.” The difference gives the coefficient, not the whole rule: 3*n* gives 3, 6, 9, not 5, 8, 11. The constant must be adjusted by testing the first term, giving 3*n* + 2.

## 6.3 Function machines and linear graphs

**Criterion C · II · B · III** · Related concepts: Models, Representation

> A function machine is a sequence rule written as a process: it takes an input, applies the rule once, and gives an output. Its graph shows every input and output at once.

[Figure: function_machine — A function machine applying × 3 + 1. Working backwards undoes the operations in reverse order.]

A machine can be read in three directions: forwards from input to output; backwards from output to input, undoing each operation in reverse order; and sideways, as the graph of *y* = 3*x* + 1, which is a straight line.

**Worked example 6.3.1 — Forwards and backwards**

A machine applies the rule × 3 + 1. Find the output for input 7, and the input that gives output 25.

1. Forwards: 7 × 3 = 21, then 21 + 1 = 22.
2. Backwards: undo “+ 1” by subtracting 1, giving 24.
3. Undo “× 3” by dividing by 3: 24 ÷ 3 = 8.
4. Check forwards: 8 × 3 + 1 = 25, as required.

*Answer:* Output 22; input 8

*Check:* Undoing in reverse order is essential: subtracting 1 before dividing would give the wrong input.

**Worked example 6.3.2 — Plot and describe**

Plot the outputs of *y* = 2*x* + 1 for *x* = 0, 1, 2, 3 and describe the graph.

1. Compute the pairs: (0, 1), (1, 3), (2, 5), (3, 7).
2. Plot them on axes with *x* horizontal and *y* vertical.
3. The points lie on a straight line; extending it cuts the *y*-axis at 1.
4. The gradient is 2: each step of 1 across gives a step of 2 up.

*Answer:* A straight line through (0, 1) with gradient 2

*Check:* The constant in the rule is the intercept; the coefficient is the gradient.

**Worked example 6.3.3 — Interpret a real graph**

A plumber's charge is *C* = 25*h* + 40 for *h* hours. Interpret the numbers and find the charge for 3.5 hours.

1. 40 is the charge when *h* = 0: the call-out fee.
2. 25 is the gradient: the charge per hour.
3. For *h* = 3.5: 25(3.5) + 40 = 87.5 + 40 = 127.5.
4. The charge is £127.50.

*Answer:* £40 call-out plus £25 per hour; £127.50

*Check:* Check *h* = 1: £65, which is the call-out plus one hour's work.

“The graph of *y* = 3*x* + 1 passes through the origin because the rule is linear.” It passes through (0, 1), not (0, 0). Only a proportional rule has no constant term, and only its graph goes through the origin.

## 6.6 Summary, revision and reflection

### What this chapter established

- A sequence is a list generated by a rule; the term-to-term rule describes the step, the *n*th term describes any term directly.
- A linear sequence has a constant common difference, which becomes the coefficient of *n* in its formula.
- The constant in the formula is fixed by testing the first term.
- A function machine can be worked forwards and backwards; backwards means undoing in reverse order.
- The graph of a linear rule is a straight line whose gradient is the common difference and whose intercept is the value at *n* = 0.
- A generalisation needs a reason, not just three matching terms.

**Vocabulary to use precisely**

**sequence** · **term** · **term-to-term rule** · **common difference** · **linear sequence** · ***n*th term** · **function machine** · **input** · **output** · **gradient** · **intercept** · **generalise**

### Misconceptions to close

| The mistake | What is really happening |
|---|---|
| “The common difference is the *n*th term.” | The difference gives the coefficient: 3*n* + 2, not 3*n*. |
| “Three terms prove the rule.” | Many rules fit three terms. A generalisation needs a structural reason, usually from the diagram or context. |
| “A linear graph passes through the origin.” | Only a proportional rule does. *y* = 3*x* + 1 meets the *y*-axis at 1. |
| “Working backwards means undoing the operations in the same order.” | Undo them in reverse order: subtract before dividing if the machine added before multiplying. |
